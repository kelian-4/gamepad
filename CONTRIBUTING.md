# Contribuer à Gamepad

Merci de t'intéresser au projet. Les contributions sont les bienvenues : corrections, améliorations, nouvelles dispositions de manette, traductions, idées.

## Licence

Le projet est publié sous licence **GNU GPL v3** (voir le fichier `LICENSE`). En contribuant, tu acceptes que ta contribution soit publiée sous cette même licence.

## Proposer une modification

1. Fais un fork du dépôt.
2. Crée une branche.
3. Fais ta modification, avec un message de commit clair qui explique ce qui change et pourquoi.
4. Ouvre une pull request vers `dev`.

Avant d'ouvrir ta pull request :

- Garde le code sans commentaires : le code doit se lire de lui-même, avec des noms clairs.
- Si tu n'as pas de Mac, tu peux vérifier que l'app iOS compile avec GitHub Actions.
- Une pull request = un sujet. Évite de mélanger plusieurs changements sans rapport.

Pour signaler un bug ou proposer une idée, ouvre une issue en décrivant ce que tu faisais, ce qui s'est passé et ce que tu attendais.

Les pull requests et les issues doivent être écrites à la main, avec tes propres mots. Les textes générés par une IA ne sont pas acceptés.

## Portages vers d'autres plateformes (Android, etc.)

Les portages de l'app vers Android, ou vers toute autre plateforme, sont acceptés et encouragés, à ces conditions :

- Le portage doit être **open source**, sous la licence **GPL v3 ou ultérieure**, comme le reste du projet.
- Les changements doivent être **partagés avec le projet** : pull request vers ce dépôt, ou dépôt public lié depuis le README, pour que tout le monde en profite.
- Le portage doit rester compatible avec le serveur existant et son protocole, sans le casser pour les autres plateformes. Si une évolution du protocole est nécessaire, propose-la d'abord dans une issue.

La licence GPL v3 impose déjà de publier le code source de tout portage ou dérivé sous la même licence. Le partage avec le projet est une demande du mainteneur, qui permet de garder un seul projet vivant plutôt que des copies éparses.
